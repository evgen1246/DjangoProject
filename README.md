DjangoProject — это веб-приложение на Django, разработанное в рамках учебного курса.
Проект включает базовую настройку Django, создание приложения `catalog`, а также реализацию шаблонов с использованием Bootstrap для стилизации.
## Функциональность

- Настройка виртуального окружения и Django проекта
- Приложение `catalog` для управления товарами/услугами
- Домашняя страница с приветствием
- Страница с контактной информацией
- Использование Bootstrap для адаптивного дизайна

## Технологии

- **Python** 3.14.3
- **Django** 4.x / 5.x
- **Bootstrap** 5
- **Poetry** для управления зависимостями
- **Git** для контроля версий


## Установка и запуск

### 1. Клонирование репозитория

```
git clone https://github.com/evgen1246/DjangoProject.git
cd DjangoProject
```

3. Установка зависимостей
# Если используете Poetry
```
poetry install
```

# Или через pip (при наличии requirements.txt)
```
pip install -r requirements.txt
```


4. Применение миграций
```
python manage.py migrate
```

5. Запуск сервера разработки
```
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000
